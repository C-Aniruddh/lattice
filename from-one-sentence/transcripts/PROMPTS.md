# Round three — two verbs each, and a reason to care

Rounds one and two used beacons, market and canals: one verb apiece, repeated.
They exercised core, iso, draw, loop, input and ui, and left three packages
untouched by any agent in any run — audio, sim and persist.

These keep forcing those three, and add exactly one thing: a SECOND verb that
interacts with the first, plus a pressure that makes the choice matter. The
complexity is in the interaction, not in more content — two verbs that talk to
each other beat one verb and a bigger map.

  claude : a game where you hang chimes along a mountain path and tune each one,
           so the wind plays them in order as walkers pass
           -> audio + iso.path + placement. Place AND tune; the walkers make the
              sequence, so the puzzle is a melody you assemble in space. Pitch has
              to be exact and the gesture-unlock has to be handled. Our own looking
              harness is blind to sound, which is the point.

  codex  : a game where you plant an orchard and each evening choose to harvest or
           let it grow, and it keeps growing while the tab is closed
           -> sim + persist. Two verbs with a real tradeoff, a decision per cycle,
              and the only prompt that cannot be satisfied unless the tab actually
              closes. Walks into two documented traps: Infinity through JSON, and
              an offline curve that must never be restarted.

  grok   : a game where you place stalls and open gates to pull the crowd to your
           bakery before the market closes
           -> input placement + iso.path + a clock. Footprint, ghost, validity, the
              tap->tile seam, and walkers re-routing when the map changes under
              them. Most likely of the three to hit K44, the flat-ground pick error
              that is still open — so it doubles as a test of whether an unfixed kit
              bug reaches a stranger.

None of them names Lattice, isometric anything, or a package.
